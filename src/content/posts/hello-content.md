# Hello, content

This page is rendered end to end by the **qriib content platform**.

It started life as a plain Markdown file in `src/content/posts/`, was
validated against the content collection schema, and was rendered to static
HTML by Astro. No database, no server required to serve it.

That is the whole foundation: drop a Markdown file in, get a fast, cheap,
SEO-friendly page out. Everything else — authoring workflow, analytics, SEO,
monetization — builds on top of this.
